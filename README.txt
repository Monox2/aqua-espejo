LISTO PARA GITHUB PAGES
1. Sube index.html y la carpeta assets al mismo repositorio.
2. En GitHub: Settings > Pages > Deploy from a branch > main > /(root).
3. Espera unos minutos y abre la URL de GitHub Pages.

IMPORTANTE
El WhatsApp del sitio está configurado actualmente como 52 33 1234 5678, tomado de la propuesta visual.
Para cambiarlo, abre index.html y busca:
const WHATSAPP_NUMBER = '523312345678';
Sustituye ese valor por el número definitivo en formato internacional, sin espacios ni signos.
